# SEI_AFRIQUE Client Book v2.1.0 (Sei_Afrique.ng)

Shared cloud client book (Firebase) with offline copy on every phone.

## Upload to GitHub
Upload every file in this folder to the repository root (index.html, sw.js, manifest.json, logo.png, icon-192.png, icon-512.png, README.md). Same names replace the old files. Open the app online and tap "Check for update".

## Before the first login
Follow SETUP_V2.md (Firebase rules, user accounts, API key restriction). The app will not load any data until the rules and user accounts exist.

## What is new in v2
Firebase login, shared data for the whole shop, offline copy that syncs, junk basket synced across phones, CSV/Excel import with preview, black and nude look, several items per visit, finance records, weekly and monthly finance reports (manual and automatic), "Add visit".
