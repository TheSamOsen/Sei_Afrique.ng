# SEI_AFRIQUE Client Book (Sei_Afrique.ng)

## Put it online free (pick ONE)
- Netlify Drop (easiest): go to app.netlify.com/drop and drag this whole folder in. You get a link like https://something.netlify.app.
- GitHub Pages: new repo, upload these files, Settings > Pages > Deploy from branch (main, root).
- Cloudflare Pages: Workers & Pages > Create > Pages > Upload assets.

## Install on a phone (works offline after the first open)
- iPhone/iPad: open the link in Safari > Share > Add to Home Screen.
- Android: open in Chrome > menu > Install app.
- Windows/Mac: Chrome or Edge > install icon in the address bar.

## Google Drive
Follow "How to set up" inside the app (free Google Cloud Console steps). Use your live web address as the Authorized JavaScript origin.

## Updating the app
Replace index.html on your host (same link). Open the app online and tap "Check for update". Client data is not touched by updates.

## Add-ons (v1.2.0)
- WhatsApp messages to clients (outfit ready, balance reminder, fitting)
- Printable receipts (Print / Save as PDF)
- Measurement history with one-tap restore
- Sewing history and payment history per client (numbered, permanent records)
- Sewing and payment records can be edited or deleted (v1.3.1)
- v1.4.0: returning clients (Add to job / visits), password for edit and delete, junk basket
- v1.5.0: every visit is a full record (measurements, payments, photos); visit history, visit report and all-visits CSV
